# 数据、模型及证据的边界

## 身份与化学

同一连接骨架不等于同一立体异构体。联合语料优先以完整InChIKey处理精确身份，单独保留连接层键；盐、互变异构体、混合物与未确定手性必须保留处理规则。图模型与SMILES都不应丢弃手性。天然来源、推测来源、半合成与合成类似物分别标记。

## 标签与实验

结构数据库可用于无监督学习；没有实验标签的结构不提供ADMET或疾病监督。计算logP、QED、SA、对接和模型预测属于计算结果。实测溶解度、活性、毒性与暴露需要条件、单位和来源。缺失标签不是0；未报道关系不是负例。正例与未标注学习、证据加权、域适应等方法见算法目录，但必须逐项验证。

## 疾病证据

区分获批适应症、指南推荐、临床试验、动物实验、细胞实验、结合或计算假说。药物本体、衍生物及联合治疗不能混同。图上的关联路径不自动证明因果，也不构成治疗建议。当前适应症模块提供证据检索；没有训练校准过的疾病疗效头。

## 评估与适用域

同一分子或重复样本必须处在同一个拆分。骨架、时间、来源与研究分组应结合实际部署场景；跨库重叠必须去重检查。模型选取只用验证集，最终测试不参与调参。模型不使用未来token的图信息帮助因果语言解码。预测的不确定性、适用域及外部验证必须单独报告，单个试验拆分不证明泛化优势。

## 数据获取与许可

可下载不等于可商业再分发。公开GitHub保留代码与目录，原始数据按各自条款单独打包。CC0、CC BY、CC BY-SA、NC、ND与未核实条件分别记录。数据包不授予超出原始来源的权利。固定版本、URL、检索时间、文件大小、SHA256和实际下载失败均随清单保存；本地SHA256不是发布方签名。

COCONUT的上游collection列表只是来源目录，不等于分别获取其中每个数据库。NPASS论文报告的ADME条目与当前提供的下载表分开记录；没有取得对应表时不把论文统计当成已下载标签。THEOBROMA原始PostgreSQL dump可保存，但未实际恢复时不能声称独立统计了其中所有化合物。

## 本版交付

本项目为紧凑的结构/性质联合研究模型，既有代码也有真实试验训练权重。大型结构包可供后续预训练，但交付的试验模型不宣称在全部结构上完成训练。所有数量与指标以当前交付清单及检查点文件为准。
