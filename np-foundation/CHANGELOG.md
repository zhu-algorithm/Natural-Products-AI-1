# Changelog

## 0.2.0 — 2026-11-15

### NP-GPT 结构语言模型

- 新增本项目用 PyTorch 编写的 decoder-only Transformer：causal SDPA、RoPE、RMSNorm、SwiGLU、可配置 GQA、权重绑定和 KV cache。使用已有架构方法；没有加载外部预训练权重。
- 新增 SQLite 与 memmap 语料准备、按来源连接层身份稳定划分、训练分区拟合词表、完整序列预算和排除审计。原始输入字符串用于训练，规范结构另存作身份审计。
- 发布实际完成一整轮训练的 331,680 参数 CPU 检查点，遍历 688,166 条合格训练序列、45,457,285 个预测 token、11,296 次更新。
- 验证和测试各使用固定抽取的 4,096 条序列；同测试集合的 unigram/bigram 基线、训练报告和完整生成 attempts 随模型发布。
- 新增 `npfm np-gpt prepare/train/generate/score/evaluate` 命令。序列表征返回 EOS/mean 向量与 NLL；OOV、超长及分词失败保留状态，不截断或补占位向量。
- 保存安全加载所需的分片 hash、配置和词表 hash；精确断点续训验证优化器、随机数、数据游标及运行配置，要求相同输出目录。
- 公开 checkpoint 仅保存一套推理权重分片。实际已见公开语料行号以无损差分压缩保存并附恢复方法；模型分发不包含原始训练数据或优化器恢复状态。

### 结果与边界

- 同测试集 token NLL 0.658853、perplexity 1.932575；这些是结构序列指标，不是 ADMET、药效或临床成功概率。
- 固定 512 次生成中，RDKit 有效 439 次、独特有效结构 434 个；新颖性分别相对指定训练集合与全语料快照核对。保留所有失败尝试，不以补采样提高分母表现。
- `small`/`base` 仅为未训练配置模板。更大规模模型、药理监督和临床适应症预测不属于本次已训练能力。
- 保留 v0.1 的结构/图融合模型、实测 logS pilot、化学工具、资源目录、下载器和证据检索接口；旧 checkpoint 和对应指标属于独立模型族。
