罗汉果非甜苷类成分挖掘与高值化利用：操作手册

版本 1.0 · 用于项目立项、实验执行、算法分析、工艺放大和质量审计

适用范围：罗汉果原料、甜苷生产副产物及其非甜苷类小分子、黄酮/多酚、糖苷、多糖和膳食纤维相关研究。每个阶段必须完成质量门后才可进入下一阶段。
不可省略的原则：AI/机器学习用于排序、注释和生成可检验假设；不可代替结构确证、原始实验、毒理评估、人体研究、产品合规或疾病治疗结论。

0. 项目启动与责任分工

必须指定的角色
  • 项目负责人：冻结研究问题、目标和放行决定。
  • 分析化学负责人：样品、仪器序列、特征表和结构证据。
  • 分离工艺负责人：DoE、回收路线、规模化与成本。
  • 药理/营养负责人：细胞、动物、终点与伦理。
  • 生物信息负责人：微生物组、多组学、统计与代码。
  • 质量/法规负责人：原料规格、污染物、标签和产品边界。
项目启动包（未齐全不得开题）
  • protocol_v1.pdf：主要假设、主要终点、入排标准、样本量、统计方案。
  • sample_manifest.csv：样品 ID、物种/部位、批次、工艺节点、日期、保存条件。
  • data_dictionary.xlsx：变量、单位、允许值、缺失编码。
  • analysis_manifest.json：软件版本、参数、随机种子、运行人。
启动质量门：研究问题、产品边界、样本随机化、空白/QC、主要终点和统计分析计划均须在查看结果前冻结。
阶段 1

原料、批次与原始数据登记

操作步骤

  1. 为每份原料、提取物、分级组分和分离物创建不可复用 ID，例如 LHG-2026-B03-FLAV-F07。
  2. 记录物种凭证、果实部位、采收/加工日期、甜苷生产节点、溶剂/树脂/膜条件与保存条件。
  3. LC–MS/MS 分析中每 5–10 个样品插入 1 个 pooled QC；每批包含提取空白、溶剂空白和标准品。
  4. 保存原始文件、转换后的 mzML、仪器方法、序列表及文件 SHA-256 校验和。

算法与判读

数据质量算法

PCA/Robust PCA 检查 QC 聚集和样本离群；QC-RLSC 或 ComBat 只能在随机化和批次结构明确时校正漂移。

输出文件

qc_report.html、sample_manifest.csv、raw_file_checksums.txt、exclusion_log.csv。

放行：QC 不得系统性漂移；空白、批次和样品元数据完整。任何后补信息须保留审计记录。
阶段 2

非甜苷类成分挖掘与实体库优选

操作步骤

  1. 用 MZmine 对 mzML 执行质量检测、色谱构建、去卷积、同位素/加合物分组、RT 对齐和去空白。
  2. 导出 feature_table.csv（m/z、RT、MS/MS、峰面积、QC RSD）和 mgf。
  3. 将 feature table + MGF 输入 GNPS FBMN，得到分子网络；将网络中的已知甜苷簇标记为去重复参考，而不是直接删除原始记录。
  4. 将高质量 MS/MS 送入 SIRIUS，顺序运行分子式、CSI:FingerID 与 CANOPUS；按置信度分为“确证、推定、类别注释、未知”。
  5. 按网络簇代表性、丰度、批次稳定性和新颖性建立主动分离优先级。

最小参数与输出

任务算法关键控制文件
特征检测MZmine噪声阈值基于 QC；记录 ppm、RT 容差、最小峰宽feature_table.csv
分子网络GNPS FBMN / modified cosine记录谱图相似度阈值、最小匹配峰和网络版本fbmn_network.graphml
结构候选SIRIUS / CSI:FingerID / CANOPUS候选结构不得替代 NMR/标准品确证annotation_confidence.tsv
放行：实体库计数必须按可追溯实体样本和证据等级审计：非甜苷小分子≥10、黄酮/多酚≥15、糖苷类≥20为项目目标，不可用预测名称凑数。
阶段 3

副产物分级回收与纯化工艺

操作步骤

  1. 按可溶性多糖、不溶性膳食纤维、黄酮/多酚、糖苷和小分子提取物定义组分池及目标检测方法。
  2. 建立工艺因子表：溶剂比例、pH、温度、时间、固液比、膜截留、树脂类型、洗脱条件、能耗与成本。
  3. 先用 D-optimal 或 Box–Behnken 设计建立初始实验矩阵；每个设计点至少保留重复和工艺空白。
  4. 以得率、目标组分含量/纯度、成本和安全为多目标，使用高斯过程或 TPE 贝叶斯优化提出下一轮实验。
  5. 对最终候选工艺做连续独立批次验证，并报告误差与失败批次。

分析公式与算法

工艺模型

PLS/RF 回归：工艺因素 → 得率/纯度/特征峰；用置换检验与留批次验证防止过拟合。

多目标选择

计算 Pareto 前沿，不以单一纯度或单一得率决定路线。目标提取物“纯度≥70%”必须先写清目标成分、方法学和测量不确定性。

放行：工艺窗口、批间 RSD、残留溶剂、污染物和成本均合格后，方可将组分交付功能试验。
阶段 4

3T3-L1、HepG2 与肥胖/高胆固醇模型功能验证

操作步骤

  1. 先注册主要终点、次要终点、阳性/阴性对照、剂量、样本量、随机/盲法和排除标准。
  2. 每个测试物必须链接到批次、纯度、结构证据、溶媒和暴露浓度；细胞/动物实验不得混用未确认批次。
  3. 至少设置 5 个浓度或合理梯度，先获得毒性窗口，再进行主要功能终点研究。
  4. 对细胞数据以板/日期为随机效应；对动物数据以笼位、性别、基线等预设协变量建模。

算法与输出

剂量与批次

四参数 Hill/Log-logistic 剂量反应；线性/广义线性混合效应模型。输出 dose_response_report.html、效应量、95%CI 和毒性窗口。

多终点控制

Benjamini–Hochberg FDR；主终点优先，保留原始点图。输出 endpoint_results.tsv，包括未校正与校正 P 值。

放行：对照有效、独立重复、毒性窗口和主要终点达到预设标准，才能进入机制、肠菌群或配方研究。
阶段 5

肠菌群与多组学机制

操作步骤

  1. 采集粪便/内容物时同步记录饮食、笼位、抗生素、批次、采样时间和冷链；包含提取空白、PCR 空白和 mock 群落。
  2. 使用 DADA2/QIIME 2 去噪并生成 ASV 表；先进行污染与测序深度审计，再做差异丰度。
  3. 用 ANCOM-BC 或 ALDEx2 进行组成型差异分析；协变量预先写入模型。
  4. 以嵌套交叉验证运行 Elastic Net 或 Random Forest；SHAP 仅解释通过外层验证的模型。
  5. 将微生物组、代谢组和功能表型用 DIABLO/MOFA 整合；候选模块需用补充/阻断实验验证。
放行：不得把相关性、SHAP 排名或网络边直接写为因果机制；至少需要独立队列或干预性实验验证。
阶段 6

产品配方、剂型与健康食品转化

操作步骤

  1. 仅使用已经完成身份、稳定性、初步安全和功能证据门的组分进入配方库。
  2. 为每种候选记录规格、溶解/分散性、口感、稳定性、微生物限度、成本、供应和法规约束。
  3. 使用 Scheffé 混料设计或 D-optimal 混料设计建立首轮配方；不可凭经验直接定义唯一配方。
  4. 以组分保留、稳定性、感官、成本为目标，以安全/法规为硬约束进行贝叶斯多目标优化。
  5. 对 Pareto 配方做真实时间稳定性、微生物、感官与批间验证；不同产品类别由质量/法规团队确认合规路径。
放行：健康食品/特医食品/院内制剂属于不同监管路径；配方模型不能构成任何疾病预防、治疗或人体功效结论。
阶段 7

谱效关联、质量标志物与产品质量标准

操作步骤

  1. 锁定工艺批次的指纹图谱、功能终点和标准品数据；训练批次与外部验证批次必须分离。
  2. 用 PLS/OPLS 建立初筛模型，同时进行交叉验证和置换检验。
  3. 用 LASSO/Elastic Net 取得稀疏候选峰；用 RF/SVR 检验非线性一致性，所有模型均采用嵌套交叉验证。
  4. 候选 Q-marker 必须同时具备可测性、批次工艺关联、功能关联和外部验证，之后再进行靶向定量与方法学验证。
放行：不得以训练集准确率或单一相关系数确定质量标志物；必须报告外部批次性能、稳定性与失败样本。

8. 归档、版本与论文级报告

每个阶段必须归档
  • 原始数据、分析脚本、环境文件、软件版本和随机种子。
  • 参数文件、输入/输出文件 SHA-256、异常/排除日志。
  • 实验原始记录、盲法/随机化、伦理与质控记录。
  • 完整结果表，而非仅保留显著结果或最佳图。
论文/结题最小包
  • README.md：数据字典、复现顺序与硬件/软件依赖。
  • analysis_manifest.json：每个算法的输入、参数、版本、结果文件。
  • validation_report.pdf：独立批次、负对照、外部验证和局限性。
  • decision_log.csv：每一次“继续/阻断/回退”的依据。
最终放行：项目负责人、分析化学、工艺、药理/营养、生物信息和质量/法规负责人共同签署；任何未验证算法结论均标注为“研究假设”。
