第 3 步 · 生成 AI 成分挖掘计划

点击后您会拿到什么

AI 在后台安排的工作
  • 信号整理：去除空白/噪声，将同一物质的同位素、加合物等信号归并。
  • 成分家族整理：将 MS/MS 相似的成分自动聚类，找出已知簇和未知簇。
  • 结构候选排序：给出可能的分子式、化学类别和候选结构，并标出证据强弱。
  • 分离优先级：综合新颖性、丰度、谱图质量和可分离性，提出下一批优先分离对象。
完成后研发人员看到的报告
  • 样本与质控报告：哪些样本通过、哪些受空白/批次影响。
  • 成分信号清单：m/z、保留时间、各样本丰度、MS/MS质量、是否值得关注。
  • 成分家族图：哪些信号可能属于同一类化合物，哪些是未知簇。
  • 候选证据卡：分子式、类别、候选结构、参考谱/文献和证据等级。
  • 分离建议：优先馏分、目标特征和需要 NMR/标准品确认的项目。
报告怎么看

将技术文件翻译成化学研发语言

分析引擎产生的文件研发人员看到的内容可据此做的决定
feature table / MGF每个样本中可比较的化学信号清单，以及每个信号的 MS/MS 证据。确认批次差异、丰度高低和候选峰是否值得跟进。
分子网络结构相似的成分自动组成“家族”；已知和未知成员显示在同一图中。识别可能的新化学系列，避免重复分离已知成分。
formula / class / candidate每个候选的分子式、可能化学类别、可能结构和证据等级。决定是否购买标准品、进行靶向检测或开展 NMR 确证。
优先分离队列结合新颖性、丰度、MS/MS质量和可分离性形成的下一步建议。安排色谱分离、制备量和结构鉴定资源。
重要：“候选结构”不是“已确证化合物”。进入实体化合物库前仍需实物可追溯、HRMS、1D/2D NMR、纯度等结构证据。
