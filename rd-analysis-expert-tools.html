使用范围：本客户端提供本地、可复现的预分析和项目分流，不替代 MZmine、GNPS、SIRIUS、DADA2、QIIME 2 或经验证的统计/生物信息计算环境。导入正式数据前请先用下方模板核对字段。

1. 化学成分特征表：空白/QC 本地筛选

适用于完成 MZmine 等预处理后导出的 feature table。要求列：feature_id,mz,rt,sample_mean,blank_mean,qc_rsd；程序实际计算 blank_ratio = blank_mean / sample_mean。

2. 肠菌群差异丰度：本地 BH-FDR 与效应量

用于 DADA2/QIIME 2/ANCOM-BC 等上游流程后的结果复核。要求列：feature_id,case_mean,control_mean,p_value；客户端计算 log2 fold-change 和 Benjamini–Hochberg FDR。

3. 配方数据：多目标 Pareto 前沿

适用于混料设计或稳定性/感官实验后的配方筛选。要求列：formula_id,retention,stability,sensory,cost,safety_pass；前 3 项越高越好，成本越低越好，safety_pass 必须为 TRUE。

4. 重型算法任务包

以下算法不能在纯静态网页中可靠执行。选择任务后可下载 JSON manifest，交给配置相应软件的本地工作站/HPC/服务器运行，并回传结果文件进入上述本地复核流程。
