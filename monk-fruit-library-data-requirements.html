罗汉果多类别化学成分库：建库数据要求与检索规范

将研发人员掌握的一手样本、提取、分离和原始谱图数据，与可追溯的外部化学/文献/谱图检索分开管理；AI 负责辅助归并和排序，实体化合物仍以实物与结构确证为准。

建库不是“把名称填进表格”。信息库记录样本、特征、注释、文献和不确定性；实体化合物库记录真实可取用的样品。两库通过样本 ID、馏分 ID、feature ID 和实体 ID 连通，但准入标准不同。
先建立六层数据主链

每一条候选化合物都必须能回到原料和原始数据

原料层植物鉴定、来源、部位、采收、留样
提取物层工艺、批号、得率、溶剂、储存
馏分层分离条件、收集窗口、得率、去向
特征层m/z、RT、MS/MS、空白/QC状态
注释层类别、候选结构、证据和文献
实体层样品瓶、结构确证、纯度、库存、位置
不可省略的规则：没有 raw_material_id、extract_id、fraction_id、feature_id 或 physical_entity_id 中相应链路的记录，不能声称该候选“来自本项目罗汉果样本”。
研发人员必须提供

信息库的最小交接包

数据包必须输入字段/文件责任团队入库前检查
植物与原料学名、鉴定人/凭证标本号、品种或来源、产地、经纬度精度、采收时间、部位、干燥/贮存、照片原料/植物学团队名称与凭证、批号和留样位置可追溯；产地等敏感信息按权限管理
提取物谱系extract_id、原料 ID、粉碎、溶剂、固液比、pH、温度、时间、浓缩、除杂、得率、操作人、日期、储存制备/工艺团队每个提取物可回溯到唯一原料批次；工艺版本冻结
色谱/分离记录fraction_id、柱/填料、流动相、梯度、检测波长、收集窗口、得率、纯度、父提取物/馏分分离纯化团队父子关系完整；失败分离也记录，供 AI 主动学习使用
原始化学数据供应商原始文件及 mzML/mgf；MS1/MS2、正负离子、空白、QC、内标、标准品、进样顺序、仪器与方法文件分析/质谱团队空白、QC 与样本批次可区分；文件校验值、采集参数和软件版本保留
确证与库存HRMS、1D/2D NMR、比旋/绝对构型证据（适用时）、纯度方法/色谱图、样品质量、浓度、冻融、位置结构鉴定/样品库团队实体样本可定位、可复测；结构证据等级与纯度明确
研发人员需要查询/核对

外部证据不能替代项目原始数据，但必须按结构与来源复核

查询目的推荐资源与检索方式应保存到信息库的字段边界
化学结构与同义名以 SMILES、InChIKey、分子式、精确质量或结构子结构查询 PubChem；必要时用已获许可的 SciFinder-n/Reaxys 复核结构版本、InChIKey、SMILES、PubChem CID、同义名、查询日期、来源链接名称命中不等于本项目样本中存在；CAS 仅作辅助标识，不作为唯一键
天然来源与首次报道PubMed、Web of Science、CNKI/万方及有许可的天然产物工具书/数据库；使用学名 + 部位 + 化合物/骨架 + 分离/鉴定等检索式DOI/PMID、物种、部位、分离/定量方法、证据摘录、适用范围文献中的同名物/异构体必须核对结构与谱图，不能仅凭名称合并
MS/MS 参考谱GNPS/MassIVE、MassBank、MoNA 等公开谱库；按仪器、离子模式、碰撞能和加合物匹配谱库 accession、相似度、谱图条件、匹配峰、查询日期、注释等级谱库匹配是注释证据，不自动构成结构确证
分类与去重复以已证实 mogroside/甜苷标准品和内部谱库为参照；并做文献/结构相似性检索甜苷关联状态、类别概率、已知/未知簇、去重复依据不得把“未匹配甜苷”直接称为非甜苷；应保留不确定性
AI 在建库中的位置

AI 负责整理和排序，不替代结构确证

AI 可执行
  • 从 LC–MS/GC–MS 原始数据提取特征，进行空白扣除、QC 评估、RT 对齐、同位素/加合物归并。
  • 使用分子网络、分子式、化学类别预测和谱图相似性建立候选注释。
  • 结合新颖性、丰度稳定性、MS/MS 质量和可分离性，对数百/数千特征排列优先级。
  • 基于既往分离成败，用主动学习/贝叶斯优化提出下一轮分离条件。
AI 不可替代
  • 植物鉴定、样本真实性、工艺真实记录和原始数据完整性。
  • 新化合物的结构与立体化学确证、纯度放行和实体样品管理。
  • 文献事实核查、数据库许可审查与科学责任判断。
  • 把候选注释直接写成“已发现/已分离的化合物”。
两库分别准入

信息库与实体化合物库不要混用

库允许纳入的对象最低证据必须显示的状态
多类别化学成分信息库原料、提取物、馏分、质谱特征、候选结构、文献条目、已确证化合物有可追溯来源和原始/处理数据；候选注释注明证据级别未注释 / 类别注释 / 候选结构 / 标准品匹配 / NMR确证
实体化合物库可定位、可取用的物理样品实体 ID、来源链、HRMS + 1D/2D NMR（或同等充分证据）、纯度、数量和库位可用 / 待复测 / 低库存 / 冻结 / 耗尽
发布级质量门：原始数据、元数据、数据处理参数、注释来源、负结果、结构证据和库存状态均可回溯。代谢组报告标准强调生物样本背景、化学分析和数据分析信息应一同保存；这也是本平台将“研发输入”置于 AI 之前的原因。
HerbNova R&D · 罗汉果成分建库执行规范：研发人员的一手数据决定库的可靠性，AI 提升解析和分离效率，实体确证决定最终入库。
