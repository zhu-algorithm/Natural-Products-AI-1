固定分析流程

化合物身份→多源靶点证据→疾病遗传/组学→PPI 与通路→置换/FDR→外部验证→结构与实验
  1. 以 InChIKey 去重，冻结 SMILES、立体化学、盐型、pH 质子化态与批次质控。
  2. 靶点边按直接结合、功能实验、人工整理库、相似性预测和 ML 预测分层；同源预测不能与其源数据库重复计为独立证据。
  3. 疾病基因分层输入：遗传学、患者 bulk/scRNA-seq、药物靶点和动物模型。发现集与验证集必须独立。
  4. 富集使用明确背景集，输出基因数、OR、95% CI、BH-FDR、完整表和 ID 映射；用度数匹配随机网络与疾病基因置换获得经验 P 值。
  5. 只有通过外部验证的靶点/模块才进入结构对接；对接后仍需结合与功能实验确认。
