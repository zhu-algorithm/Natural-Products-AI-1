罗汉果非甜苷类成分：信息库与实体库算法

研发人员提供可追溯的提取物谱系和原始化学数据；AI 从大量谱图特征中完成去噪、归并、注释、去重复与分离优先级排序，最后以实物和结构确证形成可审计化合物库。

核心原则：需要研发人员的数据。AI 不能替代提取、色谱、质谱、NMR 和标准品比对。LC–MS 中的“数百个特征”是待分析信号，不应直接写成“数百个已鉴定化合物”；只有结构证据、纯度和实物样本都达到要求的条目，才进入实体化合物库。
研发人员提供的输入

两类“谱系”与三层化学数据

样本/提取物谱系（必需）
  • 植物学鉴定、品种/来源、产地、采收期、部位、干燥与贮存。
  • 提取批号、粉碎粒度、溶剂、固液比、温度、时间、pH、浓缩/纯化节点、得率和留样位置。
  • 每个提取物与原料、馏分、后续实体样本均由不可重复 ID 串联。
化学分析数据（必需）
  • LC–HRMS/MS 原始文件或 mzML/mgf；空白、QC、标准品、内标与进样顺序。
  • 按化学空间补充 GC–MS（挥发性/低极性）及 1D/2D NMR（分离物结构确证）。
  • 若比较品种或生态型，可额外提供 DNA 条形码/遗传分型；它用于解释化学型差异，不替代化学分析。

从数百个信号到非甜苷实体库的闭环

0. 谱系冻结样本—提取物—馏分 ID 链
1. 多平台采集LC–HRMS/MS、GC–MS、NMR；空白/QC
2. 特征发现MZmine 去噪、对齐、同位素/加合物归并
3. AI 注释GNPS、SIRIUS、CSI:FingerID、CANOPUS
4. 去重复排序已知甜苷排除、谱图相似度、新颖性和可分离性
5. 主动分离贝叶斯优化色谱；实测结果回写模型
6. 确证入库HRMS/NMR/标准品、纯度、库存与谱图绑定

AI 如何处理“数百种非甜苷候选”

raw signals → feature table (m/z, RT, intensity, MS2) → merge isotope/adduct/in-source fragments → molecular entities\nentity score = 0.30 × novelty + 0.25 × MS2_quality + 0.20 × abundance_stability + 0.15 × non_glycoside_probability + 0.10 × isolation_feasibility\npriority queue = only entities passing blank/QC/reproducibility gates; select next fractions by expected information gain per separation cost\n每轮分离：输入 fractionation_log + NMR/HRMS truth → 更新候选结构置信度与下一轮分离队列。

非甜苷分类门

先定义范围，再由算法筛选

建立经标准品或可靠谱图确认的 mogroside/甜苷参考库，用于标记已知甜苷相关信号；对其余特征，AI 输出“非甜苷类概率、化学类别和结构候选”，而不是强行二元判定。黄酮/多酚、小分子、糖苷等类别应分别汇报已确证数、候选数和未注释数。

论文级质量门：空白扣除、QC RSD、缺失率、批次漂移、同位素/加合物归并、注释等级、去重复依据、原始数据与软件参数必须归档。信息库可收录候选条目并标明证据等级；实体库只收录已获得实物、可追溯、结构与纯度证据达标的条目。
